# Claude Code local setup

Este repo trae configuracion local para Claude Code.

## Que debe hacer cada dev

1. Abrir Claude Code desde la raiz de este repo
   - recomendado: `./scripts/claude`
2. Confirmar que existe `CLAUDE.md` en la raiz
3. Trabajar usando los skills locales versionados en `.claude/skills/`

## Skills incluidos

- `karpathy-guidelines`
- `ui-ux-pro-max`
- `ui-styling`
- `design-system`
- `svelte-runes`
- `svelte-components`
- `svelte-styling`
- `svelte-template-directives`
- `sveltekit-structure`
- `sveltekit-data-flow`

## Origen de los skills

- `forrestchang/andrej-karpathy-skills`
- `nextlevelbuilder/ui-ux-pro-max-skill`
- `spences10/svelte-skills-kit`

Se dejaron versionados localmente para que el equipo no dependa de instalaciones globales ni de marketplace.
